# 생성형 AI 활용 로그

공지 4번 ②의 기록 항목(사용 도구, 활용 수준, 주요 활용 내용, 팀에서 검토·수정한 부분, 팀이 직접 결정한 설계)을
그때그때 한 줄씩 남깁니다. 발표 직전에 기억으로 쓰지 말고, AI를 쓸 때마다 바로 적으세요.
작성 방법은 `docs/AI-GUIDE.md` 8번을 봅니다.

## 활용 수준 기준 (공지 4번 ①)

| 단계 | 의미 |
| --- | --- |
| 0 | AI 없이 직접 개발 |
| 1 | 개념 이해, 오류 확인, 코드 설명에만 활용 |
| 2 | 일부 클래스·메서드·기능 구현에 활용 |
| 3 | 주요 기능과 클래스 구조 생성에 적극 활용 |
| 4 | 바이브코딩 중심으로 대부분 또는 전체 구현 |

## 팀이 직접 결정한 설계

- 주제: 항공권 예매 프로그램 (Java Swing)
- 로그인 추가: 프로그램 시작 시 회원가입/로그인 창, 가입하면 바로 로그인, 로그아웃 시 로그인 창으로
- 용어 "항공권"으로 통일, 편도 + 왕복, 달력 날짜 선택, 출발지별 도착지 필터, 노선·날짜별 항공권 2~3개
- 승객 정보~결제 상단에 선택한 항공권 표시, 만 나이 계산기, 결제 수단별 입력 칸, 승객 성별
- 페이지 분담: A 검색·항공권 선택 / B 승객 정보·좌석 / C 결제·예약 조회
- (추가로 결정한 것을 계속 적기)
